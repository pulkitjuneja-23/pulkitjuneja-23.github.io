# pulkitjuneja-23.github.io

Source for my personal site: https://pulkitjuneja-23.github.io

I'm a PhD student in agronomy at Texas A&M, based at the Blackland Research and
Extension Center in Temple, TX. The site covers my field trials, UAV remote
sensing and crop modeling work.

Plain HTML, CSS and JavaScript. No framework, no build step. Open `index.html`
in a browser to run it locally.

    index.html      page text
    assets/css/     styles
    assets/js/      hero animation, project panels, journey map, citations
    assets/img/     photos and logos
    assets/data/    map dots for the journey section

Map data from Natural Earth.
